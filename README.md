# 📄 File to Markdown Converter

A simple web app that converts PDF, Word, PowerPoint and Excel files into
clean Markdown format.

The project was built during my MBA programme at Chandigarh University as
a practical learning project.

## 🚀 What the App Does

The application allows users to:

- Upload PDF files
- Upload Word documents
- Upload PowerPoint presentations
- Upload Excel spreadsheets
- Convert files into Markdown
- Download individual Markdown files
- Download all converted files as a ZIP
- Continue processing even if one file fails

The converted Markdown can be useful when preparing documents for AI tools
that work better with structured text.

## 🛠️ Technologies Used

- Python
- Streamlit
- Microsoft MarkItDown
- GitHub
- Streamlit Community Cloud
